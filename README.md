# DSA-Lab2 

Just a quick collection of C++ programs I put together for my second Data Structures and Algorithms (DSA) lab. 

## What's in here?

*   `analyze_pointer.cpp` - Messing around with and testing pointers.
*   `hello.cpp` - The classic hello world environment check.
*   `isSorted.cpp` & `test_isSorted.cpp` - Code to check if an array is sorted, plus some tests to make sure it actually works.
*   `salary.cpp` - A basic salary calculation program.
*   `string_reverse.cpp` - Flipping strings backwards.

## How to run it

Make sure you have `g++` or any C++ compiler ready, then just run:

```bash
g++ filename.cpp -o program
./program
```
